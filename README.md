### <samp>02 / SELECTED WORK</samp>

#### [DocMind ↗](https://github.com/mohamedAY2004/DOCMIND)

**Course materials in. Grounded answers out.**

An AI document assistant for university education. I built the backend and contributed to the AI layer: document ingestion, retrieval, source-attributed answers, and access control for students, instructors, and admins. LLM and vector-store providers can be swapped through configuration.

`Python` `FastAPI` `PostgreSQL` `pgvector` `Qdrant` `Docker`

#### [Multiplexed TCP Chat ↗](https://github.com/mohamedAY2004/Multiplexed_TCP_ChatApp)

**Many connections. One event loop.**

A chat server built with non-blocking sockets and Python selectors, including message framing, private and broadcast messages, and file transfer.

`Python` `TCP` `Sockets` `Selectors`

#### [Egyptian Currency Detection ↗](https://github.com/mohamedAY2004/Egyptian-Currency-Object-detection)

**Computer vision beyond the notebook.**

A YOLO model for recognizing Egyptian banknotes in real time, with a desktop interface for testing camera input. Part of my work on practical, on-device vision.

`YOLO` `Computer Vision` `Python`
